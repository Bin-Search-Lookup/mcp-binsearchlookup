O servidor oficial do Model Context Protocol (MCP) para [BinSearchLookup.com](https://www.binsearchlookup.com/). Este servidor permite que agentes de IA (como Claude Desktop, Cursor e LLMs personalizados) interajam de forma perfeita e segura com a API do BinSearchLookup para realizar pesquisas avançadas de Número de Identificação Bancária (BIN), análise de fraudes e auditoria em massa de cartões.

## Recursos Enterprise
- **Diagnóstico local offline:** Identifica redes e realiza verificações locais do algoritmo de Luhn em PANs completos de 16 dígitos.
- **Divisão automática e concorrência:** Envie milhares de BINs de uma vez.
- **Cache LRU na memória:** Economiza créditos de API.
- **Limpeza estrita de entradas:** Remove traços, letras e espaços.
- **Resiliência:** Backoff exponencial integrado.
- **Implantação com Zero-Install:** Execute em um contêiner Docker.
